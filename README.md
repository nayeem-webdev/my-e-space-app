## 🌟 About the Project

My Space App aims to bring the wonders of the universe closer to everyone. Using NASA's APIs, it showcases fascinating pictures and information about our cosmos, along with the latest news from space exploration and research.

---

## 🎯 Project Goals

- **Inform:** Share knowledge and information from trusted space-related sources.
- **Engage:** Provide a visually appealing interface that captures the wonder of space.
- **Educate:** Showcase real-time data using APIs for an interactive learning experience.

---

## ✨ Key Features

- **Astronomy Picture of the Day (APOD):** Stunning daily photos with descriptions from NASA.
- **Mars Rover Photos:** Images captured by Mars rovers.
- **Space News & Articles:** Stay updated with the latest blogs and insights from the world of space research.
- **Responsive Design:** Sky-blue-themed UI that's optimized for all devices.
- **Data Caching:** Faster performance with local caching using `localforage`.

---

## 🛠️ Technologies Used

**Frontend:**
- React with React Router DOM
- Tailwind CSS for styling
- Axios for API requests
- React Icons for interactive elements

**Backend & APIs:**
- NASA APIs (APOD, Mars Rover Photos, etc.)
- Space News APIs

**Build Tools:**
- Vite for development and building

**Other Tools & Libraries:**
- LocalForage for local storage
- Match-sorter and Sort-by for efficient data sorting
